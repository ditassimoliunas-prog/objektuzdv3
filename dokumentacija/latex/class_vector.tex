\subsubsection*{template$<$typename T$>$\newline
class Vector$<$ T $>$}
Custom dynamic array container template. 

\doxylink{class_vector}{Vector$<$\+T$>$} is a generic container that stores elements of type T in a dynamically allocated array. It provides O(1) amortized time complexity for push\+\_\+back(), while maintaining contiguous memory layout like std::\+vector.

The class implements the Rule of Five pattern and fully supports deep copy and move semantics.

{\bfseries{Key Features:\+}}
\begin{DoxyItemize}
\item Dynamic memory management (automatic resizing)
\item Random access iterators (begin(), end(), rbegin(), rend())
\item Copy and move semantics (Rule of Five)
\item Standard container operations (push\+\_\+back, pop\+\_\+back, insert, erase, etc.)
\item Comparable performance to std::\+vector for most operations
\end{DoxyItemize}

{\bfseries{Memory Strategy:\+}}
\begin{DoxyItemize}
\item When capacity is exhausted, reallocates with roughly 1.\+5x growth factor
\item Tracks reallocation count for performance analysis
\item Supports manual reserve() for optimization
\end{DoxyItemize}
